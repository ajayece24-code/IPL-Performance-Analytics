# IPL-Performance-Analytics
Tableau dashboard analyzing IPL matches, teams, batsmen, bowlers and venues.

## Project Overview
An interactive Tableau dashboard designed to analyze Indian Premier League (IPL) cricket data and uncover insights into team performance, batting records, bowling statistics and venue analysis.

## Objectives
- Analyze IPL match trends across seasons.
- Identify the most successful IPL teams.
- Analyze the top 10 batsmen by runs scored.
- Identify the top 10 bowlers by wickets taken.
- Analyze the most frequently used IPL venues.

## Tools & Technologies
- Tableau Public
- Microsoft Excel / CSV
- Data Visualization
- Data Analytics

## Dashboard Features
1. Total Matches
2. Total Runs
3. Total Wickets
4. Average Runs per Match
5. Season-wise Run Trends
6. Team-wise Wins
7. Top 10 Batsmen
8. Top 10 Bowlers
9. Venue Analysis
